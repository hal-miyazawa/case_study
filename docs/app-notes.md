# App Notes

Git で共有するための、このアプリに関する作業メモです。

## 概要

- プロジェクト名: `case_study`
- 種別: React + TypeScript + Vite のフロントエンドアプリ
- 現在の画面: 防災ノベルゲームの導入から対策フェーズ、リュック確認画面までのデモ
- 主な目的: 地震発生前に何を準備するかを選び、準備内容によって災害後の展開やエンドが変わる防災ゲーム
- 企画詳細: [project-plan.md](project-plan.md)
- ストーリーと画面構成: [story-flow.md](story-flow.md)
- AI API 確認方法: [ai-api-setup.md](ai-api-setup.md)

## 技術構成

- React: `19.2.6`
- React DOM: `19.2.6`
- TypeScript: `6.0.2`
- Vite: `8.0.12`
- ESLint: `10.3.0`

## 主要ファイル

- `src/main.tsx`: React アプリのエントリーポイント
- `src/App.tsx`: 現在の主要 UI、画面遷移、対策フェーズ、リュック画面、テキストログ
- `src/App.css`: `App.tsx` 用の画面スタイル
- `src/index.css`: グローバルスタイル、フォント、選択防止など
- `src/assets/backgrounds/`: 背景画像
- `src/assets/icons/`: UI アイコン画像
- `vite.config.ts`: Vite 設定。開発用の `/api/ai-scene` もここにある

## 実行コマンド

```bash
npm install
npm run dev
npm run build
npm run lint
```

## 現在の実装メモ

- 最初は `予告本画面.png` を背景に、主人公が『ワイが見た未来』を見て不安になる導入が進む。
- 導入後に暗転を挟んで `通常部屋画面.png` へ移る。
- 通常部屋で短い会話を挟んだあと、暗転中に `-対策フェーズ開始-` を表示する。
- 対策フェーズでは左上に `対策フェーズ`、右上に `残り3日` を表示する。
- 右下付近に `テキストログ` と `UI非表示` ボタンを常時表示する。
- 対策フェーズでは `ショップicon.png` と `リュックicon.png` を表示する。
- 現在、リュックアイコンを押すと `リュック画面.png` を背景にしたリュック確認画面へ移動する。
- リュック画面では、持っているアイテム一覧を右側に表示する。
- アイテム一覧は18項目あり、スクロールできる。
- アイテムをホバーするとテキストボックスに説明が出る。
- アイテムをクリックすると `〇〇を使いますか？` と表示し、`はい` / `いいえ` ボタンを出す。
- テキストログでは、これまで表示されたセリフを確認できる。最新ログが下に来る。
- `UI非表示` は背景確認用。リュック画面では表示しない方針だったが、現在は常時表示に変更済み。
- OpenAI API 連携の開発用エンドポイントは残っているが、現時点の導入からショップ到達前までは AI を使わない方針。
